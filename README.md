# 🎮Jogo Runner 2D com Raylib

Um jogo 2D simples do tipo **runner/endless runner** feito em **C++** com a biblioteca **[Raylib](https://www.raylib.com/)**. O jogador controla um quadrado azul que precisa pular obstáculos vermelhos que vêm em sua direção. Cada obstáculo desviado vale pontos — sobreviva o máximo que puder!

## 📖 Sobre o Projeto

Este projeto foi criado como um **primeiro contato com desenvolvimento de jogos** usando C++ e Raylib. Ele demonstra os conceitos fundamentais de um game loop:

- **Inicialização** de janela e contexto gráfico
- **Update** (lógica de física, colisão, spawn de obstáculos)
- **Draw** (renderização de retângulos e texto)
- **Cleanup** (fechamento ordenado dos recursos)

Apesar de simples, o código é uma base sólida para expandir para jogos mais complexos.
